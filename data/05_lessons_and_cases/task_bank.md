# Банк задач RetailPulse

## Уровень 1
1. Найти 10 самых дорогих товаров.
2. Посчитать общую выручку.
3. Посчитать заказы по статусам.
4. Посчитать средний чек.
5. Найти клиентов с более чем 3 заказами.
6. Посчитать выручку по категориям.
7. Найти месяц с максимальной выручкой.
8. Посчитать долю мобильных заказов.
9. Найти топ-10 брендов по выручке.
10. Найти товары, которые ни разу не продавались.

## Уровень 2
11. Посчитать repeat purchase rate.
12. Посчитать return rate по категориям.
13. Сравнить AOV по каналам.
14. Найти клиентов без покупок последние 90 дней.
15. Найти категории, где возвраты выше среднего.
16. Сравнить acquisition_channel.
17. Построить воронку session_start → product_view → add_to_cart → checkout_start → purchase.
18. Сравнить конверсию по устройствам.
19. Исследовать связь рекламных кампаний и продаж.
20. Найти города с высокой выручкой и высоким уровнем возвратов.

## Уровень 3 — Data Engineering
21. Написать incremental loader по updated_at.
22. Реализовать retry с exponential backoff.
23. Сохранять checkpoint после каждой страницы.
24. Сделать загрузку идемпотентной.
25. Валидировать JSON через Pydantic.
26. Записывать ошибки загрузки в отдельный лог.
27. Сделать повторный запуск безопасным.
28. Добавить тесты на transformation order_items.
29. Проверить referential integrity.
30. Запустить pipeline по расписанию через Airflow.

## Финальный кейс

Руководитель хочет ежедневный отчёт по продажам.

Данные приходят из API. Необходимо:
- получать только новые/изменённые заказы;
- сохранять raw;
- валидировать данные;
- устранять дубликаты;
- рассчитывать метрики;
- записывать результат в PostgreSQL;
- формировать витрину;
- запускать процесс автоматически;
- добавить тесты и Data Quality;
- обеспечить безопасный повторный запуск.
