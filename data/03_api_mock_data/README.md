# Mock Orders API

JSON-файлы имитируют постраничный REST API интернет-магазина.

- 60 000 заказов
- 60 страниц по 1 000 записей
- `page`, `page_size`, `has_next`, `next_page`
- `updated_at` для incremental loading
- данные отсортированы по `order_id`

Учебные сценарии:
1. собрать все страницы;
2. реализовать retry;
3. сделать incremental loading по `updated_at`;
4. защититься от повторной загрузки;
5. валидировать схему ответа;
6. сохранять checkpoint последней успешно обработанной страницы.
