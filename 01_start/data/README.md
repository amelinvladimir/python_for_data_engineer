# RetailPulse — набор данных для курса Python для анализа данных и инженерии данных

Основной учебный проект курса — RetailPulse, интернет-магазин.

Набор специально сделан сквозным: один бизнес-контекст используется от NumPy/Pandas до PostgreSQL, API ingestion, ETL, Data Quality, Airflow и финального проекта.

## Папки

- `01_retailpulse_csv` — CSV, включая специально «грязные» raw-данные.
- `02_retailpulse_postgresql` — Docker Compose + PostgreSQL schema + CSV.
- `03_api_mock_data` — 60 JSON-страниц, имитирующих API заказов.
- `04_parquet` — оставлена как место для создания Parquet студентами на соответствующем уроке; готовые Parquet-файлы в этой среде не генерируются из-за отсутствия Parquet engine.
- `05_lessons_and_cases` — карта применения по неделям и банк задач.

## Почему данные синтетические

Данные сгенерированы специально для обучения. Они не содержат данных реальных людей. При этом в них есть реалистичные связи, временная динамика, бизнес-сценарии и намеренные проблемы качества.

Все имена, идентификаторы, суммы и даты вымышлены.
